# 🌌 太阳系探索 — H5 科普互动作品

> 基于 HTML5 Canvas 技术开发的交互式太阳系科普应用

## 📋 作品简介

**太阳系探索**是一款基于 HTML5 技术开发的交互式科普作品，通过精美的星空动画和丰富的交互设计，让用户以直观、有趣的方式探索太阳系中的八大行星和太阳。作品融合了科学数据可视化、沉浸式体验和知识测验，旨在激发公众对天文学的兴趣，普及太阳系科学知识。

## ✨ 核心功能

### 🌍 行星探索
- **点击交互**：点击任意行星或太阳，查看详细的科学数据和趣味知识
- **实时动画**：行星按照真实公转比例在轨道上运行
- **缩放平移**：支持滚轮缩放和拖拽平移，自由探索太阳系

### 📊 数据对比
- **行星对比**：选择任意行星与地球进行多维度数据对比
- **可视化图表**：直观的条形图展示行星间的差异

### 📏 比例模式
- **可视化模式**：行星大小和轨道经过艺术化处理，便于观察
- **真实比例模式**：按照真实天文数据展示行星大小和轨道距离

### 🧠 知识测验
- **15道精选题目**：涵盖太阳系各行星的科学知识
- **随机出题**：每次测验随机抽取10题，保持新鲜感
- **即时反馈**：答题后立即显示正确答案和科学解释

### 🎨 视觉效果
- **动态星空**：闪烁的星星和偶尔划过的流星
- **行星细节**：木星条纹、大红斑、土星环、地球大陆、火星极冠
- **光影效果**：行星表面的光照和阴影效果
- **日冕光晕**：太阳的辐射光晕效果

## 🔬 科学原理及内容

### 天文学基础知识
- 太阳系的组成：太阳（恒星）+ 八大行星 + 矮行星 + 小天体
- 行星分类：类地行星（水金地火）vs 气态巨行星（木土）vs 冰巨行星（天海）
- 开普勒行星运动定律：行星轨道为椭圆，周期与距离的关系

### 物理学原理
- 万有引力定律：天体间的引力作用
- 温室效应：金星极端高温的成因
- 核聚变反应：太阳能量的来源（E=mc²）
- 潮汐锁定与自转：行星自转周期的差异

### 各行星核心知识
| 行星 | 关键特征 |
|------|---------|
| 水星 | 最小、昼夜温差最大（600°C+）、有磁场 |
| 金星 | 最热（462°C）、逆向自转、极浓大气层 |
| 地球 | 唯一有液态水和生命的行星、有磁场保护 |
| 火星 | 红色星球、最高山峰（奥林匹斯山）、有探测器 |
| 木星 | 最大、大红斑风暴、95颗卫星、强磁场 |
| 土星 | 壮观环系统、密度低于水、146颗卫星 |
| 天王星 | "躺着"自转（98°倾斜）、可能有钻石雨 |
| 海王星 | 最远、最快风速（2100km/h）、数学预测发现 |

## 💡 设计思路

### 交互设计理念
- **探索式学习**：用户通过主动点击、缩放、拖拽来探索，而非被动阅读
- **渐进式信息**：从概览（轨道动画）→ 详情（行星信息）→ 深入（数据对比）→ 检验（知识测验）
- **即时反馈**：所有交互都有即时的视觉和信息反馈

### 视觉设计理念
- **沉浸式星空**：深色背景 + 动态星空营造宇宙氛围
- **信息层次**：通过颜色、大小、动画区分信息的优先级
- **响应式设计**：适配桌面和移动设备

### 技术选型理由
- **纯前端实现**：HTML5 + CSS3 + JavaScript，无需后端服务器
- **Canvas 2D**：高效的 2D 渲染，适合实时动画
- **模块化架构**：各功能模块独立，便于维护和扩展

## 🛠️ 技术架构

```
solar-system-explorer/
├── index.html              # 入口页面
├── css/
│   └── style.css           # 样式（响应式布局、星空主题）
└── js/
    ├── planets.js          # 行星科学数据
    ├── stars.js            # 星空背景渲染
    ├── canvas.js           # 太阳系 Canvas 渲染引擎
    ├── ui.js               # UI 交互管理
    ├── quiz.js             # 知识测验模块
    └── main.js             # 主程序入口
```

### 核心技术点
- **Canvas 2D 渲染**：行星绘制、轨道动画、光影效果
- **requestAnimationFrame**：60fps 流畅动画
- **事件系统**：鼠标/触摸事件统一处理、拖拽与点击区分
- **碰撞检测**：圆形碰撞检测用于行星点击判定
- **坐标变换**：缩放和平移的矩阵变换
